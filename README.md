# 🎯 Угадай число (от 1 до 50)

**Простенькая консольная игра на C++**, где нужно угадать случайное число.

## 📝 Описание

Это классическая игра для командной строки. Компьютер загадывает случайное число в диапазоне от 1 до 50, а ваша задача — угадать его. После каждой попытки вы будете получать подсказку: ваше число больше или меньше загаданного.

Цель игры — угадать число за наименьшее количество попыток.

## ⚙️ Как играть

1.  Запустите программу.
2.  Введите число от 1 до 50.
3.  Получайте подсказки:
    *   "Меньше!" — если ваше число больше.
    *   "Больше!" — если ваше число меньше.
4.  Продолжайте, пока не угадаете число.
5.  Когда угадаете, программа поздравит вас и покажет количество потраченных попыток.

## 🚀 Запуск

### Инструкция по сборке и запуску

1.  **Клонируйте репозиторий:**
   ```bash
    git clone https://github.com/yaroshin228/GuessTheNumber.git
   ```

2.  **Перейдите в директорию**
   ```bash
   cd GuessTheNumber/src
   ```

3.  **Соберите проект**
   ```bash
   mkdir build && cd build
   cmake ..
   make
   ```

4.  **Запустите игру**
   ```bash
   ./GuessTheNumber
   ```
