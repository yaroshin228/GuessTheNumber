# Угадай число (GuessTheNumber)
Простая консольная игра на C++, где нужно угадать случайное число от 1 до 50.

## Правила
1.  Запустите программу.
2.  Введите число от 1 до 50.
3.  Получайте подсказки:
    *   "Меньше!" — если ваше число больше.
    *   "Больше!" — если ваше число меньше.
4.  Продолжайте, пока не угадаете число.
5.  Когда угадаете, программа поздравит вас.

## Сборка
   ```bash
   cd GuessTheNumber
   mkdir build && cd build
   cmake .. && make
   ```
